# TradeKing

> TradeKing was a US online brokerage offering self-directed trading of stocks and options, backed by Battery Ventures. It was acquired by Ally Financial in 2016 and rebranded as Ally Invest; the TradeKing developer API lives on as the Ally Invest API. tradeking.com now redirects to https://www.ally.com/invest/ and the historical API hosts (api.tradeking.com, developers.tradeking.com) no longer resolve.

TradeKing pioneered a public brokerage API (the TradeKing API) that let developers manage self-directed accounts, place equity and options orders, stream real-time market quotes, and manage watchlists using OAuth 1.0. After the Ally Financial acquisition that surface was rebranded the Ally Invest API. This profile is maintained by API Evangelist as a historical record; the live successor is profiled separately.
